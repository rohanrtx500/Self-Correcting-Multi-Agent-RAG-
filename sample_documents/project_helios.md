# Project Helios Technical Specifications

Project Helios is an advanced solar-powered energy grid system designed for remote microgrid deployments. It leverages next-generation high-density lithium-iron-phosphate (LFP) battery cells and active cooling thermal regulation loops.

## Core Specifications

*   **Solar Panel Array Output**: 450kW peak capacity using bi-facial monocrystalline photovoltaic cells.
*   **Battery Storage Unit**: 1.2MWh capacity with battery safety control systems.
*   **Operating Temperature Range**: -20°C to 55°C.
*   **Grid Output Voltage**: 480V three-phase AC at 60Hz.

## Active Cooling Loops
To prevent battery degradation under extreme desert heat (ambient temperature > 40°C), Project Helios incorporates a self-regulating liquid glycol circulation loop. The cooling loop is designed to trigger automatically when internal battery temperatures exceed 32°C. It maintains a target operating temperature of 25°C.
